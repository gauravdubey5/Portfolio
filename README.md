## 🌌 Overview: The Cloudverse Experience

Rather than an ordinary static developer template, this portfolio immerses visitors into a futuristic **Cloudverse** &mdash; a floating digital cosmos representing cloud infrastructure, automation pipelines, and engineering achievements.

The experience integrates:
- **Real-Time 3D WebGL World (Three.js)**: Orbiting floating islands, cosmic stardust, volumetric cloud particles, glowing data bridges, and mouse-reactive parallax depth.
- **Live Cloud Infrastructure Map**: An interactive architectural visualizer of an enterprise Azure topology (VNet, DMZ & Private Subnets, NSGs, Linux VMs, Blob Storage, CI/CD Spine). Selecting components reveals live Terraform code snippets, security considerations, and source repository links.
- **Recruiter Fast-Track Mode**: A one-click toggle in the Cyber HUD that switches between the interactive 3D universe and an ultra-clean, high-density scannable recruiter layout.
- **Verified GitHub Integration**: Live GitHub REST API synchronization with fallback caching to guarantee zero broken states or rate-limit issues.
- **Operational Communications Terminal**: Live EmailJS contact transmission with real client configuration and quick email copy.

## 🛠️ Tech Stack & Engineering Standards

### Frontend & Graphics
- **Core Structure**: Semantic HTML5 with ARIA accessibility roles and unique testable IDs.
- **Styling**: Vanilla CSS3 design system with custom properties, glassmorphism, responsive grid/flexbox layouts, and `@media (prefers-reduced-motion)` compliance.
- **3D Graphics Engine**: Three.js WebGL (r128 via CDN) with graceful fallback to 2.5D CSS parallax layers on low-power devices.
- **Web Audio API**: Procedural atmospheric drone synthesizer (disabled/muted by default, accessible on-demand).

### Integrations & Tooling
- **GitHub REST API**: Dynamic profile telemetry & repository cards with offline caching.
- **EmailJS**: Direct client-side message transmission with spinner and cyber toasts.
- **Font Awesome 6 & Google Fonts**: Plus Jakarta Sans and JetBrains Mono.

## 🚀 Running Locally

Clone the repository:
```bash
git clone https://github.com/gauravdubey5/Portfolio.git
cd Portfolio
```

Start any local web server:
```bash
# Using Python:
python -m http.server 4173

# Or using Node.js:
npx serve .
```

Open `http://localhost:4173` in your browser.

## 🌐 Deployment Compatibility

This repository is optimized for **Cloudflare Pages** and **GitHub Pages**:
- **Pure Client-Side**: No backend build server required; zero build steps needed.
- **Relative Asset Paths**: All stylesheets, scripts, images, and resume links resolve reliably across root or subpath deployments.
- **High Performance**: CDN assets are cached, and the WebGL canvas automatically pauses rendering when the browser tab is hidden to conserve system resources.
