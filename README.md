# 📖 Overview

This portfolio showcases my journey as an aspiring **Azure DevOps Engineer**. It highlights my technical expertise, cloud projects, GitHub repositories, certifications, and hands-on experience with Infrastructure as Code (IaC) and CI/CD automation.

The website is fully responsive and dynamically fetches my latest GitHub repositories using the GitHub REST API.
